# 📌 Visão Geral do Projeto
O café é um fenômeno global e, a cada ano, milhares de novas cafeterias são abertas no mundo, com destaque para o crescimento do mercado de cafés especiais.

Este projeto analisa um conjunto de dados de pesquisas com aproximadamente 1.000 entusiastas de café para identificar as escolhas de leite mais populares. O objetivo principal é fornecer recomendações baseadas em dados para uma nova cafeteria especial que planeja operar exclusivamente com bebidas vegetais (plant-based).

## 🛠️ Etapas do Projeto
Carregamento dos Dados: Importação do dataset de pesquisas de café utilizando a biblioteca Pandas.

Seleção de Colunas: Filtragem das colunas irrelevantes para focar exclusivamente nas perguntas sobre opções de leite e alternativas vegetais.

Renomeação de Colunas: Limpeza e padronização dos nomes das colunas (transformando perguntas longas de formulário em rótulos curtos e objetivos).

Compreensão dos Dados: Inspeção de tipos de dados, tratamento de valores ausentes e validação das frequências em perguntas de múltipla escolha.

Preferências de Laticínios: Agregação e cálculo da distribuição das escolhas de leite favoritas entre os consumidores.

Visualização dos Resultados: Criação de um gráfico de barras horizontal para ranquear as opções e destacar as principais alternativas vegetais.


## 🚀 Tecnologias Utilizadas
Python 3.12.10

Pandas (Manipulação e Limpeza de Dados)

Matplotlib / Seaborn (Visualização de Dados)

Jupyter Notebook / VS Code
