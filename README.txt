# 📊 Data Science Essentials with Python

## Sobre o Projeto

Este repositório contém os projetos e exercícios desenvolvidos durante o curso **Data Science Essentials with Python**, com foco nos fundamentos da Ciência de Dados utilizando Python.

O curso apresenta como transformar dados brutos em informações relevantes através de técnicas de limpeza, organização, análise e visualização de dados.

Durante o desenvolvimento do projeto foram utilizados recursos da linguagem Python e bibliotecas amplamente utilizadas na área de dados, como **Pandas** e **Matplotlib**, permitindo explorar datasets reais e criar análises visuais para facilitar a interpretação das informações.

---

## 🎯 Objetivos do Curso

- Aprender os fundamentos de Ciência de Dados utilizando Python;
- Trabalhar com conjuntos de dados reais;
- Realizar limpeza e preparação dos dados;
- Criar gráficos e visualizações para comunicar resultados;
- Identificar padrões e tendências através da análise de dados;
- Desenvolver a capacidade de transformar dados em insights.

---

## 🛠️ Tecnologias Utilizadas

- Python 🐍
- Jupyter Notebook
- Pandas
- Matplotlib

---

## 📚 Conhecimentos Desenvolvidos

### 🧹 Limpeza de Dados
- Tratamento de valores ausentes;
- Organização de datasets;
- Correção e padronização de informações;
- Preparação dos dados para análise.

### 📊 Visualização de Dados
- Criação de gráficos e tabelas;
- Representação visual de informações;
- Comparação entre diferentes categorias;
- Comunicação de resultados através de dados.

### 🔎 Análise de Dados
- Exploração de datasets;
- Identificação de padrões;
- Extração de informações relevantes;
- Interpretação dos resultados encontrados.

---

## 📈 Projetos Desenvolvidos

Ao longo do curso foram realizados projetos práticos utilizando dados reais, aplicando técnicas de:

- Manipulação de dados com Pandas;
- Análise exploratória;
- Criação de visualizações com Matplotlib;
- Geração de insights a partir dos dados.

---

## 🚀 Aprendizados

Ao finalizar este projeto, desenvolvi conhecimentos fundamentais para trabalhar com Ciência de Dados, incluindo a capacidade de preparar dados, analisar informações e apresentar descobertas de forma clara e visual.
